# Mycelium Starter

**TL;DR:** This repo holds an untouched Angular 21 starter project, exactly as the Angular CLI generates it, with no app code added. Nobody uses it, and its intended purpose (perhaps a template for new Mycelium apps) is not written down anywhere.

## What it is

The output of `ng new` for Angular 21.2, from 2026-05-15, plus a generated `mycelium.json` manifest. The only screen is the CLI's
placeholder page and the route list is empty. There is no Firebase config, no deploy workflow and
no `package-lock.json`.

## What's in here

| Path | What it is |
|---|---|
| `src/app/` | The CLI starter component and empty routes. |
| `angular.json`, `package.json`, `tsconfig*.json` | Angular 21 project `mycelium-starter`, Vitest for tests. |
| `.vscode/` | Editor settings from the CLI. |
| `mycelium.json` | The repo's Mycelium manifest, generated by the dev-policy tooling. |

## Run it locally

```bash
npm install
npm start          # ng serve on http://localhost:4200
```

## Build and test

`npx ng build` builds it; `npm test` runs the CLI's one Vitest spec. There is nothing to deploy.

## Status

Dormant, unversioned (`0.0.0`).
